# موقع شركة أبراج (Abraj Group)

موقع تعريفي احترافي بصفحة واحدة، لمجموعة أبراج بفرعيها:
- **أبراج الماضونة للخدمات الأمنية** (حراسات، حماية، نقل أموال...)
- **أبراج للخدمات المساندة** (تنظيف، صيانة، هيلبر، إدارة مشاريع...)

الموقع بُني بـ HTML + CSS + JavaScript خالص (بدون أي أدوات بناء)، لذلك يعمل مباشرة على GitHub Pages بدون أي إعداد إضافي.

## محتويات المجلد
```
index.html     ← الموقع كامل (كل الأقسام + التصميم + الأكواد)
favicon.svg    ← أيقونة الموقع
CNAME          ← ملف الدومين المخصص (horses2002.com)
.nojekyll      ← يمنع GitHub من معالجة الملفات كـ Jekyll
README.md      ← هذا الملف
```

---

## 1) رفع الموقع على GitHub

### الطريقة الأسهل (من المتصفح مباشرة)
1. ادخل إلى https://github.com وسجّل الدخول.
2. اضغط **New repository**.
   - اسم المستودع: `abraj-site` (أو أي اسم تفضله).
   - اجعله **Public**.
   - **لا** تفعّل "Add a README file" (عندنا واحد جاهز).
3. بعد إنشاء المستودع، اضغط **uploading an existing file**.
4. اسحب/ارفع كل الملفات الموجودة في هذا المجلد (`index.html`, `favicon.svg`, `CNAME`, `.nojekyll`, `README.md`) دفعة واحدة.
5. اضغط **Commit changes**.

### أو عبر الطرفية (Git)
```bash
cd abraj-site
git init
git add .
git commit -m "Abraj Group website - initial launch"
git branch -M main
git remote add origin https://github.com/USERNAME/abraj-site.git
git push -u origin main
```
(استبدل `USERNAME` باسم حسابك على GitHub)

---

## 2) تفعيل GitHub Pages
1. داخل المستودع، اذهب إلى **Settings → Pages**.
2. تحت **Build and deployment → Source** اختر: **Deploy from a branch**.
3. تحت **Branch** اختر: `main` والمجلد `/ (root)`.
4. اضغط **Save**.
5. انتظر دقيقة أو اثنتين، وسيظهر رابط مؤقت شبيه بـ:
   `https://USERNAME.github.io/abraj-site/`
   افتحه للتأكد أن الموقع يعمل قبل ربط الدومين.

---

## 3) ربط دومين هوستنجر (horses2002.com) بالموقع

الملف `CNAME` الموجود في المستودع يحتوي مسبقًا على `horses2002.com`، وهذا يخبر GitHub أن هذا هو الدومين المخصص للموقع. يبقى فقط توجيه إعدادات DNS من لوحة هوستنجر إلى GitHub.

### أ) من لوحة تحكم Hostinger (hPanel)
1. سجّل الدخول إلى hPanel → اختر الدومين `horses2002.com` → **DNS / Nameservers**.
2. أضف السجلات التالية (احذف أي سجلات A أو CNAME قديمة تشير لموقع آخر على نفس الاسم):

**سجلات A** (للدومين الرئيسي `horses2002.com`) — أضف 4 سجلات A بنفس الاسم `@` تشير إلى عناوين GitHub الرسمية:
```
Type: A   Name: @   Value: 185.199.108.153
Type: A   Name: @   Value: 185.199.109.153
Type: A   Name: @   Value: 185.199.110.153
Type: A   Name: @   Value: 185.199.111.153
```

**سجل CNAME** (لنسخة www، اختياري لكن مستحسن):
```
Type: CNAME   Name: www   Value: USERNAME.github.io.
```
(استبدل USERNAME باسم حسابك على GitHub)

3. احفظ التغييرات. انتشار DNS قد يستغرق من 10 دقائق حتى 24 ساعة.

### ب) من إعدادات GitHub Pages
1. ارجع إلى **Settings → Pages** في المستودع.
2. تحت **Custom domain** اكتب: `horses2002.com` ثم اضغط **Save**
   (GitHub سيتحقق تلقائيًا من ملف CNAME، وسيؤكد الربط بعد انتشار الـ DNS).
3. بعد التحقق، فعّل خيار **Enforce HTTPS** لتشفير الموقع بشهادة SSL مجانية من GitHub.

بعد اكتمال هذه الخطوات سيعمل الموقع مباشرة عبر `https://horses2002.com`.

## 4) تعديل محتوى الموقع لاحقًا
كل محتوى الموقع (النصوص، الأسعار، بيانات التواصل، جدول العملاء) موجود داخل `index.html`. يمكنك تعديل أي نص مباشرة داخل الملف بأي محرر نصوص، ثم رفع النسخة المعدّلة على GitHub (Commit changes)، وسيتحدث الموقع المباشر تلقائيًا خلال دقيقة أو اثنتين.

- نموذج التواصل في قسم "تواصل معنا" يرسل الطلب حاليًا عبر البريد الإلكتروني (mailto) مباشرة من متصفح الزائر. إذا رغبتم لاحقًا بنموذج يُرسل تلقائيًا بدون فتح برنامج بريد (عبر خدمة مثل Formspree أو Web3Forms)، يمكن إضافته بسهولة.
- جدول "عملاؤنا" وأسعار الباقات مأخوذة من ملفات الشركة المرفقة، ويمكن تحديثها بسهولة من داخل الكود (قسم `<script>` في نهاية الملف لجدول العملاء).
